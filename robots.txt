# The site is currently hidden from search engines and AI crawlers.
#
# 1. SEARCH ENGINES
# Crawling is intentionally left ALLOWED below so that search engines can fetch
# each page and see its <meta name="robots" content="noindex, follow"> tag.
# Blocking with Disallow would stop them reading that tag, and previously
# indexed URLs could keep showing in results.
#
# 2. AI CRAWLERS
# The noindex tag is a search-index directive; it does not reliably stop AI
# crawlers. Those are opted out by user-agent below. This is honour-based --
# compliant operators respect it, others ignore it -- and it only affects
# FUTURE crawls of this site. It cannot remove anything already collected.
#
# To make the site searchable again: switch the noindex meta tag on every
# .html page to "index, follow" and remove the AI crawler groups below.
